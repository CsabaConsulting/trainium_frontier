## Seed discipline (no seed hunt — dropped 2026-09-16)

A public-best seed hunt is selection bias: best-of-N on the visible eval
overstates the true gain, and expected transfer to the pinned private shard is
~zero. Worse, locking a "lucky" seed early distorts every later comparison.
Instead: **fix seed 42 as the control seed for all comparisons**, and only at
the very end re-verify the final config on 2–3 seeds, judging by the average
across eval defs, never the public-best outlier. Use the known spread (~0.006)
as a significance bar: future improvements must clear ~0.003 to count as
signal, not noise.

## Between-run device hygiene (2026-09-17)

Modern Neuron (1.16+) has NO resettable daemon: the runtime is libnrt linked
into each process, so device memory is per-process and freed on exit — there
is no nvidia-smi-style reset command (`neuron-ls/top/monitor` are
read-only; no reset tool ships in /opt/aws/neuron/bin). Between runs:
1. `ps aux | grep train.py` must be empty AND `fuser /dev/neuron0` silent —
   orphans hold cores/memory (kill strays; the ENOSPC SIGTERM cascade is the
   known leak vector: dying mid-compile with in-flight work).
2. `df -h /` — never compile under ~5G free (ENOSPC poisons compiles).
3. Stale `/tmp/neuron_compile_service_*.sock*` regenerate on their own; leave
   them unless a compile fails oddly, then clear socket + workdir and retry
   once before escalating.
Reboot remains the last resort only (offered, not yet taken: phase_timer
proves device+compiler healthy on default graphs, so stuck HW state is
unlikely — a reboot changes none of the compile inputs).
