## Revisit policy (user direction 2026-09-16)

Horizon is ~2 weeks, so CLOSED means "parked with reopen conditions", not dead —
except where the evidence is terminal for every variant (byte-loss linear form).
Every closed item names what would reopen it (new SDK, new width, new theory).
Bigger multi-day tasks (NKI attention port, compiler-flag tracks) are scheduled
explicitly below rather than shrunk to fit a day. When in doubt, document the
reopen condition instead of deleting the idea.

## Seed discipline (no seed hunt — dropped 2026-09-16)

A public-best seed hunt is selection bias: best-of-N on the visible eval
overstates the true gain, and expected transfer to the pinned private shard is
~zero. Worse, locking a "lucky" seed early distorts every later comparison.
Instead: **fix seed 42 as the control seed for all comparisons**, and only at
the very end re-verify the final config on 2–3 seeds, judging by the average
across eval defs, never the public-best outlier. Use the known spread (~0.006)
as a significance bar: future improvements must clear ~0.003 to count as
signal, not noise.

4. **FP8 — STAGED RESEARCH TRACK (reopened 2026-09-16, user call).**

   `neuronx-cc` exposes `--auto-cast all --auto-cast-type fp8_e4m3` (release
   notes; tutorial pattern `NEURON_CC_FLAGS="--auto-cast all --auto-cast-type
   fp8_e4m3"`). Status on our boxes (checked 2026-09-16): neuronx-cc 2.26 on
   BOTH — no `--auto-cast` in `--help`; the flag needs SDK ≥ 2.27. PyPI IS
   reachable from the boxes, so an upgrade is feasible.
   - Stage 1 (box CPU + venv work, no training): clone venv (NEVER touch
     native_venv), `pip install -U neuronx-cc` to ≥2.27, verify the flag exists.
     Kill: no newer wheel installs cleanly.
   - Stage 2 (300-step smoke, one box): same locked shape + compiler auto-cast;
     watch (a) compile success — known risk: activation-table-limit errors on
     transformer backward (upstream issue #1314); (b) steps/s vs 0.84 baseline;
     (c) loss sanity (FP8 convergence is documented-fragile: keep grad-clip on,
     be ready with loss scaling). Kill: compile fails unfixably, or steps/s ≤
     baseline, or loss diverges.
   - Stage 3 (full 1800 s, seed 42): only on a stage-2 win. Score raw bpb.
   Sources: awsdocs-neuron trainium2 arch (TFLOPS), neuronx-cc 2.27 release
   notes (flag), Medium/TDS Neuron optimization tutorial (pattern + stability
   caveats). Fits the ~2-week horizon; queued after wave-2 runs.

7. **Loss weighting by token byte-length — CLOSED 2026-09-16 (full-budget negative).**
   Smoke was mechanically clean (flag live through NKI path, sane scale) but full
   1800 s seed 42: **1.052163 vs 1.004363 dense (+0.048)**. Lesson: mean CE already
   approximates bpb well because byte mass concentrates in frequent short tokens;
   upweighting rare long tokens starves the tokens that dominate both train and
   eval. Log: `run-logs/sub1-p48-bwloss-{smoke,full}.log`. Do not revisit without
   a new theory (e.g. square-root weights); the linear version is dead.
8. **Checkpoint averaging (single model at eval).** Average last-k checkpoints
   (or EMA trajectory points) into one stateless model for `load_for_eval`.
   Legal if the submitted artifact is one static model. Near-zero cost.
