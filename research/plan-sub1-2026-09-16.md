Budget: each full run costs one 1800 s Trainium2 slot. Rule for every item:
**beat 1.004355 same-definition, in-budget, or stop.** Smoke (300-step) first
where noted; promote only on smoke wins.

## Seed discipline (no seed hunt — dropped 2026-09-16)

A public-best seed hunt is selection bias: best-of-N on the visible eval
overstates the true gain, and expected transfer to the pinned private shard is
~zero. Worse, locking a "lucky" seed early distorts every later comparison.
Instead: **fix seed 42 as the control seed for all comparisons**, and only at
the very end re-verify the final config on 2–3 seeds, judging by the average
across eval defs, never the public-best outlier. Use the known spread (~0.006)
as a significance bar: future improvements must clear ~0.003 to count as
signal, not noise.

## P4 — data-pipeline variants (cheap, rules-safe)

6. **Reshuffle / repack variants.** Different document ordering, packing, and
   epoch-boundary handling. Read-only changes to the input stream; each gets
   one full-budget slot only if 300-step smoke shows a loss-curve separation.
7. **Loss weighting by token byte-length (read-only).** Weight each token's
   loss by its byte length — closer to the bpb objective than mean CE, no
   model change, no extra state. Smoke first.
8. **Checkpoint averaging (single model at eval).** Average last-k checkpoints
   (or EMA trajectory points) into one stateless model for `load_for_eval`.
   Legal if the submitted artifact is one static model. Near-zero cost.
