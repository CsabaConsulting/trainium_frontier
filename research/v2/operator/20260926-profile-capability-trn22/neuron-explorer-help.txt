Usage:
  neuron-explorer [OPTIONS] <command>

A tool to understand the performance of a workload using the Neuron SDK.
Provides commands to capture and perform analysis on a hardware profile (NTFF)
given a Neuron-compiled model (NEFF).


Application Options:
  -v, --version  Show version and exit

Help Options:
  -h, --help     Show this help message

Available commands:
  capture       Capture a profile given a NEFF
  inspect       Inspect a workload and capture both system and device profiles
  show-session  Show information about a NTFF
  upload        Upload profiles to a specified profiler server
  view          Analyze a NEFF and NTFF to generate reports in various available formats
