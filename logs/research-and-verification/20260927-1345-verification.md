## Per-arm verdicts

### 1. Shared-statistics two-target CE — PASS_FOR_IMPLEMENTATION_ONLY

Pass is limited to a bounded off-host prototype on exactc239; preserve head
projection, target shifts, masks, runtime weights, mean/none semantics, outer
upstream scaling, BF16 boundaries and token-only evaluation. Parent calls the
CE pair twice on the same BF16 logits and repeats tanh/exp/reduction. Sharing
work is a supported hypothesis; current critical-path cost remains unknown.

The proposed real-number formula passed216 cases and independent finite
differences. But native forward uses a target-centered exp reduction, so its
two saved FP32 LSE values need not coincide bitwise. Native backward returns
each branch in BF16 before autograd adds them. A concrete counterexample:
g1=.0900156925645696, g2=.0168779423558568 gives separately rounded sum
.1064453125, versus .10693359375 for round-once. Any intentional statistic or
rounding change must be disclosed and independently tolerance-tested; this
review does not grant a universal identity claim.

At N32768,V8192, each BF16 logits/dlogits tensor is512MiB; two branch outputs
represent1GiB of logical tensor bytes. This is arithmetic, not measured HBM
traffic, peak memory, or recoverable speed. The prior fused-head HOLD concerns
the larger projection/backward build; this narrower CE prototype is distinct.
Missing attribution still blocks an evidence-based native performance claim
or automatic host allocation. New native op registration, local production
compile, exact source/CPU review, native correctness and cold timing remain.

### 2. Early k3 target — PASS_FOR_IMPLEMENTATION_ONLY

Pass is for adding only the proposed third training target, keeping c239 k2
schedule, logits/head, data loader, optimizer, launch shape and inference path.
The PR supports a parameter-free early horizon; c239 decays k2 immediately,
whereas PR178 keeps its k2 weight constant through the first phase. The new
proposal is an explicit adaptation, not replication of that record.

Independent24-case oracle confirms T/(T-2) masked averaging, within-row y[t+2],
zero contribution in finaltwo positions, initial shares4/7,2/7,1/7 and recovery
of the two-target real-number objective when w3=0. Require T>=3 explicitly;
test the actual three-path implementation, BF16 gradients, disabled behavior,
causal logits and checkpoint reload later. Three always-present CE calls are
50% more CE calls, not50% more whole-step cost. Additional logical dlogits are
512MiB per microstep; real lifetime/traffic/compile cost is unknown. No extra
data or future tokens enter the model's input or inference forward.

### 3. Output-head centering — PASS_FOR_IMPLEMENTATION_ONLY

Pass is for FP32 mean subtraction over actual8192 vocabulary rows at
initialization and after completed owner update/all-gather, before cached
BF16 weight refresh, with unchanged Adam states/LR/WD. The operation is a
training optimizer projection; persist its actual weights and leave forward
and load_for_eval unchanged. Do not center only at evaluation or by batch.

Independent example preserves ordinary softmax exactly but changes softcap15
probabilities by.0117877731 maximum: the researcher correctly disclaims
softmax invariance after softcap. This is a real model change, not a harmless
cleanup. The32MiB FP32 head adds a reduction and subtraction; physical traffic,
compile cost and speed are unmeasured. Require actual replica equality,
owner-send/all-gather ordering, cache freshness, exact update count and
checkpoint/load checks. The paper's stability motivation is weak for the
currently finite c239 run; expected local gain remains UNKNOWN.
